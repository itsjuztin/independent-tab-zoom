# Privacy Policy

**Last Updated:** October 23, 2026

## Overview
**Independent Tab Zoom** is an open-source, local-first browser extension that isolates page zoom levels to individual tabs. We believe privacy is a fundamental right. This policy outlines our strict commitment to zero data collection.

## Data Collection & Storage
- **No Personal Data Collected:** We do not collect, track, log, or store any personal information, browsing history, visited URLs, or user identifiers.
- **Local Tab Scoping Only:** Zoom settings are applied strictly in memory per browser tab session. No history or user activity is tracked or transmitted.
- **No Telemetry or Analytics:** The extension contains zero tracking pixels, analytics scripts, ads, or external telemetry.

## Permissions Usage
- `tabs`: Used to query the current active tab ID and apply isolated zoom factors to the specific tab.

## Third-Party Services
This extension operates entirely locally within your browser. It does not communicate with external servers or third-party services.
